# Brand

Agent Trail's brand is a quiet technical mark for an open format, not a hosted
product badge. The system should feel like a durable terminal record and a
reference manual.

## Core Idea

The logo combines a terminal prompt, an underscore wordmark, and a trailing
line ending in a square node. It points at the format's three load-bearing
ideas:

- Agent Trail is built from coding-agent terminal records.
- `AGENT_TRAIL` is a format-native wordmark, not a hosted product badge.
- The trailing line and node signal portable session trails.

## Visual Rules

- Use sharp geometry only: square corners, 1px to 9px strokes, no radius.
- Use monochrome by default. Black on light backgrounds, white on dark
  backgrounds.
- Keep the mark at least 16px high in UI chrome and at least 32px high in
  standalone placements.
- Keep clear space around the lockup equal to the height of the underscore.
- Use `AGENT_TRAIL` for the primary wordmark.
- Use `ATF` only as the secondary Agent Trail Format mark.

## Do Not

- Do not add gradients, shadows, bevels, glow, glass, or color accents.
- Do not round corners or turn nodes into circles.
- Do not use the mark as decoration behind content.
- Do not collapse the wordmark to `AgentTrail`.
- Do not replace the prompt glyph with unrelated terminal or code symbols.
